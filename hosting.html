Hosting y dominios

Los servicios y nombres que permiten que un sitio esté disponible en Internet.

¿Qué es el hosting?

Es un servicio que almacena los archivos del sitio y los entrega a las personas que lo visitan.

  • Compartido: varios sitios comparten servidor.
  • VPS: recursos virtuales más aislados.
  • Nube: usa infraestructura en la nube.
  • Estático: adecuado para HTML, CSS y JavaScript sin backend.

¿Qué es un dominio?

Es el nombre que se escribe para encontrar una página. El DNS relaciona el dominio con el servidor correspondiente.

Pasos para publicar

  1. Organizar y revisar archivos.
  2. Elegir un servicio de hosting.
  3. Subir los archivos.
  4. Configurar el dominio.
  5. Probar enlaces y formularios.

Para PixelVault

Un hosting estático puede publicar la demostración. Una tienda real con cuentas, pedidos o pagos requiere backend y medidas de seguridad; el carrito actual no procesa pagos.
